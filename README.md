# LeadAtlas

Поиск точек бизнеса по открытым картографическим данным по всему миру.

Движок крутится 24/7, пока вы его не остановите. Каждая новая точка сразу появляется в результатах и на глобусе.

## Что внутри

- **100+ обобщённых ниш** с поднишами (косметология, барбершопы, детейлинг, шиномонтаж и дальше)
- **Синонимы** на многих языках + комбинации «ниша + город + район» в разном порядке
- Поиск по **тегам OpenStreetMap**: находит точки даже с уникальными именами вроде «у Ашота», если категория проставлена
- **Photon / OSM** — текстовый поиск по синонимам
- Фильтры в результатах: ниша и страна
- Экспорт CSV

Источники — открытые карты (OSM Overpass и Photon). Неофициальный парсинг соцсетей не используется: это ломает правила площадок. Контакты Instagram / Telegram / VK подтягиваются, если они уже указаны в открытых тегах OSM (`contact:instagram` и т.д.).
